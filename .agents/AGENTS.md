# 원스탑 관세사 AI 서비스 개발 지침 (Project Rules & Constraints)

이 파일은 원스탑 관세사 AI 서비스 개발에 참여하는 모든 AI 에이전트가 반드시 준수해야 하는 **최상위 개발 규정 및 방향성**입니다. 에이전트들은 작업 시작 전 반드시 이 규칙을 준수하고 있는지 스스로 검증해야 합니다.

---

## 1. 프로젝트 목적 및 핵심 방향성
* **본질 집중**: 본 서비스는 관세 업무의 핵심인 **사후 세액 정밀 검증**, **관세 환급 분석**, **AI HS Code 품목분류 및 분류 근거 매칭(관세율표/해설서 기반)**에 집중합니다.
* **불필요한 목업 개발 금지**: 단순 시각적 대시보드나 실무와 동떨어진 가짜 데이터를 표현하는 컴포넌트의 신규 생성을 금지합니다.
* **실무 지향**: 관세사 혹은 수출입 기업 담당자가 세액 오류를 실제로 찾아내고 소명하기 위한 **정확하고 근거 있는 데이터 흐름**을 우선적으로 구현합니다.

## 2. 개발 및 설계 원칙
* **근거 기반(Evidence-Based)**: AI가 특정 품목을 분류하거나 세액 오류를 의심할 때는 반드시 적법한 법령, 관세율표, 혹은 `raw_explanatory_notes.txt`에 기록된 해설서 등의 **명확한 참조 근거**를 화면에 노출해야 합니다.
* **단순화**: UI는 화려함보다 실용성에 집중하며, 사용자가 실제 데이터를 파싱(예: 수입신고서 PDF/엑셀 등)하고 분석 결과를 빠르게 검증하는 UI에 집중합니다.
* **데이터 일관성**: 임의로 Mock 데이터를 늘려 화면을 채우지 말고, 백엔드 엔진(존재하는 경우)과 연동하거나 실제 해설서 텍스트 데이터베이스를 참조하는 구조를 지향합니다.

## 3. 에이전트 행동 지침 (Agent Behaviors)
* **임의 변경 금지**: 기존에 잘 작동하는 핵심 로직이나 페이지를 사용자 동의 없이 리팩토링이라는 명목으로 완전히 엎어치지 마십시오.
* **상호 작용 우선**: 기능이나 컴포넌트 구조가 모호할 때는 에이전트 스스로 추측하여 개발하지 말고, 사용자에게 질문하거나 계획 단계에서 확인을 받으십시오.
* **피드백 루프**: 주요 마일스톤이 끝날 때마다 작동 상태를 점검하고 피드백을 수용하십시오.

## 4. 실행 및 배포 제약 사항 (Execution & Deployment Constraints)
* **Windows 실행 환경 준수**: Windows PowerShell 환경에서 노드 관련 명령어(`npm`, `npx`) 실행 시 execution policy 이슈가 발생하므로 반드시 `.cmd` 확장자를 붙여 실행하십시오. (예: `npm.cmd run dev`, `npm.cmd run build`)
* **백엔드 실행**: FastAPI 백엔드는 포트 8090에서 실행해야 합니다. (`python -m uvicorn backend.main:app --host 127.0.0.1 --port 8090`)
* **DB 정밀성 검증**: 중대한 백엔드 스키마나 DB 데이터 수정 완료 시, 반드시 `tools/audit_hs_master.py`를 실행하여 데이터 무결성을 검증하십시오.
